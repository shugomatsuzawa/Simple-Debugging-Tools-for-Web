BrowserBitsについて

Titleタグ・URLの取得

現在開いているタブのTitleタグと、エンコードされたURLを取得し、コピーしやすいフィールドを表示します。

使い方

フィールドをタップすると文字列が選択されます。
選択部分をもう一度タッチしてから「コピー」をタップすると、選択されている文字列をコピーすることができます。
キーボードの Command + C キーを押して、選択されている文字列をコピーすることもできます。

外部サイト移動アラート

あなたが指定したドメインと異なるページに移動した際に画面上部でお知らせします。
例えばステージング環境でWebサイトのテストをする際、誤って本番環境に接続されているリンクをタップした場合、この機能を使えばすぐに気づくことができます。

使い方

オンにする
機能の有効・無効を切り替えます。
対象ドメイン
ここに入力したドメイン以外のページにアクセスした時、画面上部でお知らせします。
対象となるドメインを入力してください。（フルWebサイトURLではありません。）
サブドメインは区別されます。
保存
ボタンをタップすると設定が反映されます。
うまく反映されない場合は、タブを再読み込みしてください。

クイックアドミン

現在開いているページのドメインに対して、あらかじめ登録した「ドメイン以降の文字列」を付けたURLをワンクリックで新しいタブに開く機能です。
例：WordPressの管理画面（/wp-admin）、ローカル開発サーバー（:8000）など。

使い方

  1. 設定画面でクイックアドミンを追加します。
  2. 対象ページを開いた状態でポップアップを開くと、該当するボタンが表示されます。
  3. ボタンをクリックすると、指定したURLに新しいタブで移動します。

設定項目

名称
ポップアップに表示するボタン名です。
対象ドメイン
カンマ区切りで指定します。未入力の場合は全ドメインが対象です。
例：example.com, staging.example.com
URLパス置換文字列
ドメイン以降を置き換える文字列です。
例：/wp-admin、:8000、:8000/wp-admin

Windowsインターネットショートカットの作成（Windows以外のみ）

現在のページのロケーションをWindowsインターネットショートカット（.urlファイル）で出力します。
他プラットフォームのユーザーにWebサイトのショートカットを共有することができます。
